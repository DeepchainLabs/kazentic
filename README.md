# Kazentic Desktop

Official downloads and signed desktop updates for Kazentic.

Installers and update files are published on the [Releases page](https://github.com/DeepchainLabs/kazentic/releases). Supported packages cover macOS, Windows, Linux AppImage, and Ubuntu/Debian.

This repository contains public distribution files and release information. Application source code and signing keys are maintained separately in private storage.

The first release is being prepared.
