# Kazentic Desktop

Your workday, team conversations and workspace updates in one desktop app.

[**Windows 1.1.3 — Startup Repair · Early Access**](https://github.com/DeepchainLabs/kazentic/releases/tag/v1.1.3) · [**macOS, Linux and Ubuntu 1.1.2 — Early Access**](https://github.com/DeepchainLabs/kazentic/releases/tag/v1.1.2)

## Work together from your desktop

- **Track your day:** start and switch assigned tasks, take breaks, and review time entries and timesheets. Native Device Tracking measures device activity separately from task time and continues eligible recording while the app runs in the tray.
- **Keep conversations moving:** direct messages, channels, threads, mentions, attachments and saved text drafts.
- **Stay informed:** a quick notification inbox, a full notification page and optional desktop alerts while the app is running.
- **Make it yours:** profile and account security, workspace switching, light/dark/system appearance, and a persistent timer across views.

Use your existing Kazentic account. Available data and tools follow your workspace permissions and subscription. You can also use [Kazentic on the web](https://app.kazentic.com).

## Early Access

Install these releases manually; production automatic updates are not enabled yet. Save pending edits, finish uploads and quit normally before replacing an existing installation. Keep your existing application data, and use the same Windows installer format when upgrading.

The macOS builds are locally signed and **not Apple Developer ID signed or notarized**. macOS may display a developer warning or request fresh Keychain authorization. Windows installers are **not Authenticode signed** and may display an unknown-publisher or SmartScreen warning. Linux desktop integration depends on the distribution and desktop environment.

Future sidebar modules, voice/video calls and screen sharing are not available in these releases. See the release notes for the full feature and platform details.
